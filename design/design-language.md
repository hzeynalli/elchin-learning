# Design language — child-friendly version of the house style

Base system (Italdizain, minimal register): porcelain ground #F3F2EE, white surfaces, graphite ink #36373B, onyx #1C1C1E
for display, copper #9F6B47 accent (rationed), ash #8E8E8A, hairline #E2E0D9, taupe #7C6A58. Fonts: Inter (UI, data) +
Cormorant Garamond (display). ~2px radius, no heavy shadows, whitespace over decoration, 1.5px outline icons.

Adaptations for a 10-year-old (student role only; parent view stays in the minimal register):
- Type 18px base, 1.5 line height; buttons ≥ 56px tall, full-width on tablet; one primary action per screen.
- Status chips: Not yet = ash outline; Emerging = taupe; Secure = copper; Mastered = copper filled. No red/green.
- Progress = thin copper bar + a big number ("12 of 38 secure"). Streak = small flame line-icon, copper.
- Coach chat: coach bubbles on porcelain, his on white; a large round "Say it" microphone button; auto-read toggle.
- Question screen: one question at a time, huge stem, answer box or 4 big option cards, "Check" button, then feedback
  panel slides in (copper tick or taupe "look again"), then "Next". Timer small, top-right, not alarming.
- Celebrations: brief, typographic ("Secure ✓  Place value to billions"), never confetti explosions.
- Language in UI: "Learn", "Check", "Try again", "Next", "Done for today". No "test", "exam", "fail" anywhere in the student UI.
- Parent view: dense tables, Inter 14px, collapsible subject → strand → skill tree, sortable urgency table.

- Monthly Knowledge Check is labelled "Memory game" in the student UI and awards points; never "test" or "check".
